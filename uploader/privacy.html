Privacy Policy: Harrison App Lab uploader

Last updated: November 7, 2026

Who uses it. Only Harrison App Lab, to manage its own YouTube channel. The tool is not available to anyone else.

What it accesses. With the owner's permission, Google gives the tool access to the studio's own YouTube account so it can upload videos and change their title, description, visibility and publish time. It reads the channel's name and ID only to check it is posting to the right channel.

What it stores. A Google sign-in token, kept on the owner's own computer and never shared. A log of the studio's uploads (file name, video ID, title, date). No other user's data is collected, stored or shared.

Sharing. Nothing is sold or shared with third parties. Data from Google APIs is used only for uploading and managing the studio's own videos, in line with the Google API Services User Data Policy, including its Limited Use requirements, and the YouTube API Services Terms of Service.

Removing access. The owner can revoke the tool's access at any time at myaccount.google.com/permissions, which stops it working immediately.
